
# Gestión-de-Issues

## Introducción

Dayli es una aplicación de productividad pensada para organizar tareas, gestionar el tiempo y mantener hábitos desde un solo lugar.

El sector de las aplicaciones de productividad se centra en herramientas digitales que ayudan a las personas a organizar sus actividades y alcanzar sus objetivos. Sus características principales son el acceso desde móviles y ordenadores, la automatización de recordatorios, la planificación y seguimiento de objetivos, la personalización y la integración con calendarios.

Dayli busca cubrir una necesidad concreta: organizar responsabilidades personales, académicas y profesionales sin depender de varias herramientas diferentes. Para ello se han analizado TickTick, Todoist y Microsoft To Do.

En esta primera etapa, Dayli prioriza la sencillez, la organización personal, la facilidad de uso y una identidad visual reconocible.

# Descripción

Dayli es una aplicación de productividad personal que permite centralizar en un único lugar la gestión de tareas, la planificación del tiempo y el seguimiento de hábitos. Está pensada para usuarios que quieren organizarse mejor sin depender de varias herramientas ni enfrentarse a interfaces recargadas.

La aplicación permite crear tareas y listas con prioridades y fechas límite, configurar recordatorios, planificar el día y la semana, y visualizar el progreso hacia los objetivos personales. Además, ofrece una experiencia personalizable y sin distracciones, con notificaciones configurables y una interfaz clara y fácil de usar.

Dayli se dirige a estudiantes, profesionales y a cualquier persona que quiera mejorar su organización diaria y crear hábitos constantes. A medida que el proyecto evolucione, se contemplan funcionalidades como la gamificación, la sincronización multiplataforma, las sugerencias basadas en inteligencia artificial y las herramientas de bienestar digital.

El objetivo común del proyecto es ofrecer una aplicación útil, sencilla, fiable y en mejora continua.
